### Core Concepts

#### 1. Setting Up Your Control Center
Before you can build, you need a workbench. We write Python code in a text editor and run it using the terminal.
* **The Engine:** Install Python (v3.10 or higher) from python.org.
* **The Canvas:** Download Visual Studio Code (VS Code), the industry-standard code editor.

#### 2. Writing Your First Script
Open VS Code, create a new file named `hello.py`, and type the following line of code exactly as shown:

```python
print("Hello, World!")
```

#### 3. Launching Into Orbit
To run your code, open your terminal inside VS Code and type:
```bash
python hello.py
```
**The Output:**
```text
Hello, World!
```
You have just successfully instructed a machine to talk back to you.

###  The Trap: The Missing Quote
Computers are brilliant but incredibly literal. If you miss even a single character, the spell breaks. 

**The Bug:**
```python
print("Hello, World!)
```
**The Error Message:**
`SyntaxError: unterminated string literal`

**How to fix it:** Look closely at the error message. A `SyntaxError` simply means you broke the rules of the language grammar. Python is pointing out that you opened a door with a quotation mark `"` but forgot to close it. Always match your quotes!
