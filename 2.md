# Variables and Simple Data Types

## Variables
```python
message = "Hello Python world!"
print(message)
```

### Naming and Using Variables
* Variable names can contain only letters, numbers, and underscores. They can start with a letter or an underscore, but not with a number.
* Spaces are not allowed in variable names, so use underscores to separate words.
* Avoid using Python keywords and built-in function names as variable names.
* Variable names should be short but descriptive.

### Avoiding Name Errors When Using Variables
```python
# This causes a NameError due to a typo in 'mesage':
message = "Hello Python world!"
print(mesage)

# Fixed version:
message = "Hello Python world!"
print(message)
```

## Strings
A string is a series of characters. Anything inside quotes is considered a string in Python, and you can use either single or double quotes.
```python
"This is a string"
'This is a string'
```

### Changing Case in a String with Methods
```python
name = "jocelyn samuel"
print(name.title())  # Output: Jocelyn Samuel
print(name.upper())  # Output: JOCELYN SAMUEL
print(name.lower())  # Output: jocelyn samuel
```

### Combining or Concatenating Strings
```python
first_name = "jocelyn"
last_name = "samuel"
full_name = first_name + " " + last_name
print(full_name)
```

### Adding Whitespace (Tabs and Newlines)
```python
# Adding a tab
print("\tPython")

# Adding a newline
print("Languages:\nPython\nC\nJava")
```

### Stripping Whitespace
You can remove extra whitespace from both sides at once using `strip()`, from the left side using `lstrip()`, and from the right side using `rstrip()`.
```python
name = " samuel "
print(name.strip())   # Output: 'samuel'
print(name.rstrip())  # Output: ' samuel'
print(name.lstrip())  # Output: 'samuel '
```

### Avoiding Syntax Errors with Strings
```python
# This causes a SyntaxError because of the unescaped apostrophe:
# message = 'samuel's son'

# Fixed version using double quotes:
message = "samuel's son"
print(message)
```

## Numbers

### Integers
You can add (`+`), subtract (`-`), multiply (`*`), and divide (`/`) integers in Python.
```python
# Addition
print(2 + 3)

# Subtraction
print(5 - 2)

# Multiplication
print(3 * 7)

# Division
print(3 / 2)

# Exponents (two multiplication symbols)
print(3 ** 2)  # Output: 9

# Order of operations (PEMDAS)
print(2 + 3 * 4)    # Output: 14
print((2 + 3) * 4)  # Output: 20
```

### Floats
Python calls any number with a decimal point a **float**. You can perform all the same math operations on floats as you can with integers.

#### Basic Float Operations
```python
print(0.1 + 0.1)  # Output: 0.2
print(0.3 + 0.24) # Output: 0.54
print(2 * 0.1)    # Output: 0.2
```

#### Extra Decimal Places (Floating-Point Precision)
Sometimes you will get an arbitrary number of decimal places in your answer. This happens in all programming languages because of how computers represent decimals in binary.
```python
print(0.2 + 0.1)  # Output: 0.30000000000000004
print(3 * 0.1)    # Output: 0.30000000000000004
```
*Note: You can use the built-in `round()` function if you need to clean up the display (e.g., `round(0.2 + 0.1, 2)` outputs `0.3`).*

#### Integers and Floats Together
* When you divide any two numbers—even if they are integers that result in a whole number—Python **always** returns a float.
* If you mix an integer and a float in any other operation, Python will also default to a float.
```python
# Division always produces a float
print(4 / 2)     # Output: 2.0

# Mixing an integer and a float produces a float
print(1 + 2.0)   # Output: 3.0
print(2 * 3.0)   # Output: 6.0
print(3.0 ** 2)  # Output: 9.0
```

### Underscores in Numbers
When writing long numbers (integers or floats), you can group digits using underscores to make them more readable. Python ignores the underscores when storing the value.
```python
universe_age = 14_000_000_000
print(universe_age)  # Output: 14000000000
```

### Multiple Assignment and Constants
* **Multiple Assignment:** Assign values to more than one variable using a single line.
* **Constants:** A variable whose value stays the same throughout the life of a program. Python doesn't have built-in constant types, so programmers use **ALL CAPS** to indicate a variable should be treated as a constant.
```python
# Multiple assignment
x, y, z = 0, 0, 0

# Constant
MAX_CONNECTIONS = 5000
```

### Avoiding Type Errors with the `str()` Function
```python
# This causes a TypeError because you cannot concatenate a string and an integer:
# age = 22
# message = "Age: " + age

# Fixed version using str():
age = 22
message = "Age: " + str(age)
print(message)
```

## Comments
Comments allow you to write notes in English within your programs. Python ignores anything following a hash mark (`#`).
```python
# Say hello to everyone
print("Hello everybody!")
```
