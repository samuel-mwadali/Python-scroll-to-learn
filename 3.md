# Lists

A **list** is a collection of items in a particular order. You can make a list that includes the letters of the alphabet, the digits from 0–9, or the names of people in your family.

Square brackets (`[]`) indicate a list, and individual elements in the list are separated by commas. It is a good practice to make the name of your list plural, such as `names`, `languages`, or `scores`.

```python
friends = ['jocelyn', 'samuel', 'brian', 'grace']
print(friends)
```

---

## Accessing Elements in a List
Lists are ordered collections, so you can access any element by telling Python the position, or **index**, of the item desired.

* **Index Positions Start at 0, Not 1:** The first item in a list is at index `0`, the second is at index `1`, and so on.
* **Negative Indexing:** Python has a special syntax for accessing the last element in a list by asking for the item at index `-1` (`-2` returns the second item from the end, `-3` returns the third, etc.).

```python
friends = ['jocelyn', 'samuel', 'brian', 'grace']

# Accessing the first element
print(friends[0])          # Output: jocelyn
print(friends[0].title())  # Output: Jocelyn

# Accessing other elements
print(friends[1].title())  # Output: Samuel
print(friends[2].title())  # Output: Brian

# Accessing the last element
print(friends[-1].title()) # Output: Grace

# Using individual values from a list
message = f"My closest friend from college is {friends[0].title()}."
print(message)
```

## Changing, Adding, and Removing Elements
Most lists you create will be **dynamic**, meaning you will build a list and then add and remove elements from it as your program runs.

### Modifying Elements in a List
To change an element, use the name of the list followed by the index of the element you want to change, and then provide the new value.

```python
languages = ['python', 'c', 'java', 'ruby']
print(languages)

languages[3] = 'javascript'
print(languages)  # Output: ['python', 'c', 'java', 'javascript']
```

### Adding Elements to a List

#### Appending Elements to the End of a List
The simplest way to add a new element to a list is to **append** the item using `append()`. This adds the item to the end of the list without affecting any other elements.

```python
languages = ['python', 'c', 'java']
languages.append('go')
print(languages)  # Output: ['python', 'c', 'java', 'go']

# Building a list dynamically from an empty list
tasks = []
tasks.append('learn python lists')
tasks.append('push notes to github')
tasks.append('build a cli app')
print(tasks)
```

#### Inserting Elements into a List
You can add a new element at any position in your list by using the `insert()` method. You do this by specifying the index of the new element and the value of the new item, which shifts every other value one position to the right.

```python
languages = ['python', 'c', 'java']
languages.insert(1, 'rust')
print(languages)  # Output: ['python', 'rust', 'c', 'java']
```

### Removing Elements from a List

#### Removing an Item Using the `del` Statement
If you know the position of the item you want to remove from a list, you can use the `del` statement. Once deleted, you can no longer access the value that was removed.

```python
tasks = ['check emails', 'write code', 'take a break']
del tasks[0]
print(tasks)  # Output: ['write code', 'take a break']
```

#### Removing an Item Using the `pop()` Method
The `pop()` method removes the **last** item in a list, but it lets you work with that item after removing it.

```python
languages = ['python', 'c', 'java', 'php']
dropped_language = languages.pop()

print(languages)         # Output: ['python', 'c', 'java']
print(dropped_language)  # Output: php
```

#### Popping Items from Any Position in a List
You can use `pop()` to remove an item from any position in a list by including the index of the item you want to remove in parentheses.

```python
languages = ['python', 'c', 'java']
first_learned = languages.pop(0)

print(f"The first language I learned was {first_learned.title()}.")
print(languages)  # Output: ['c', 'java']
```
*Tip: If you're unsure whether to use `del` or `pop()`, ask yourself if you want to use the item after removing it. If you won't use it again, use `del`; if you want to use it as you remove it, use `pop()`.*

#### Removing an Item by Value
If you only know the **value** of the item you want to remove (not its index), you can use the `remove()` method. You can also assign the value to a variable first so you can still print a reason for removing it.

```python
guest_list = ['jocelyn', 'samuel', 'david', 'grace']
cant_make_it = 'david'
guest_list.remove(cant_make_it)

print(guest_list)  # Output: ['jocelyn', 'samuel', 'grace']
print(f"\nUnfortunately, {cant_make_it.title()} cannot make it to dinner.")
```
*Note: The `remove()` method deletes only the **first** occurrence of the value you specify. If the value appears more than once in the list, you will need a loop to remove all occurrences.*

## Organizing a List

### Sorting a List Permanently with the `sort()` Method
The `sort()` method changes the order of the list permanently into alphabetical order. You can never revert to the original order.

```python
cities = ['nairobi', 'mombasa', 'kisumu', 'nakuru']
cities.sort()
print(cities)  # Output: ['kisumu', 'mombasa', 'nairobi', 'nakuru']

# Sorting in reverse alphabetical order
cities.sort(reverse=True)
print(cities)  # Output: ['nakuru', 'nairobi', 'mombasa', 'kisumu']
```

### Sorting a List Temporarily with the `sorted()` Function
To maintain the original order of a list while presenting it in a sorted order, use the `sorted()` function.

```python
cities = ['nairobi', 'mombasa', 'kisumu', 'nakuru']

print("Here is the original list:")
print(cities)

print("\nHere is the sorted list:")
print(sorted(cities))  # Also accepts reverse=True: sorted(cities, reverse=True)

print("\nHere is the original list again:")
print(cities)
```
*Note: Sorting a list alphabetically is more complicated when all the values are not in lowercase, as capital letters are interpreted differently.*

### Printing a List in Reverse Order
To reverse the original order of a list (not alphabetically, just backward from how it was entered), use the `reverse()` method. It changes the order permanently, though you can revert to the original order anytime by applying `reverse()` a second time.

```python
cities = ['nairobi', 'mombasa', 'kisumu', 'nakuru']
cities.reverse()
print(cities)  # Output: ['nakuru', 'kisumu', 'mombasa', 'nairobi']
```

### Finding the Length of a List
You can quickly find the number of items in a list by using the `len()` function. Python counts the items in a list starting with one.

```python
cities = ['nairobi', 'mombasa', 'kisumu', 'nakuru']
print(len(cities))  # Output: 4
```

## Avoiding Index Errors When Working with Lists
An `IndexError` occurs when Python cannot find an item at the index you requested.

* **Off-by-one errors:** Asking for index `3` in a 3-item list causes an error because indexing starts at `0` (indices are `0`, `1`, and `2`).
* **Empty lists:** Asking for index `-1` works on any non-empty list, but causes an `IndexError` if the list is empty.

```python
friends = ['jocelyn', 'samuel', 'grace']

# This causes an IndexError: list index out of range
# print(friends[3])

# Safe way to access the last item (as long as the list isn't empty):
print(friends[-1].title())  # Output: Grace
```
