# 🚀 Lesson 1: Say Hello to the World

In Python, we use the `print()` action to display text on the screen. The text must be wrapped in quotation marks so the computer knows it is text and not code instructions.

```python
print("Hello, World!")
```

* **Output on screen:** `Hello, World!`
* **Try it:** Anything you put inside `" "` will be shown exactly as it is.
